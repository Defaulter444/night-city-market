# Авторство и происхождение

Русская адаптация Horusian / Defaulter444, сентябрь 2026 г.

Основной функциональный код четырёх компонентов написан в проектах Lt Atlas (LtAtasEDO):

- Choom Trade: https://github.com/LtAtasEDO/Choom-Trade
- Bodega Persistent Shops: https://github.com/LtAtasEDO/Bodega-Persistent-Shops
- Diner Manager: https://github.com/LtAtasEDO/Diner-Manager
- Vendit Persistent Shops: https://github.com/LtAtasEDO/Vendit-Persistent-Shops

Точные версии и исходные коммиты записаны в `docs/UPSTREAM.json`. Копии исходных README сохранены в `docs/upstream`. Изменения этой сборки: объединение, изоляция данных, русский интерфейс, поддержка русских предметов, общее окно, проверки запросов и последовательное выполнение торговых операций.

Choom Trade использует изображение рукопожатия на основе SVG Repo Handshake SVG Vector #352785 (CC0 1.0), адаптированное Lt Atlas.
