# Графика StreetLife

Пять панорам `streetlife-city/shop/diner/vendit/trade.webp` и логотип `streetlife-logo.webp` созданы средствами ImageGen для StreetLife по присланным пользователем референсам. Панорамы — 1600 × 600, логотип — 800 × 280. Это отдельные изображения для фона; текст интерфейса остаётся настоящим HTML и не запечён в картинку.

Изображения предметов берутся из документов мира/компендиумов; портреты персонажей — из их листов. Собственную обложку можно выбрать в редакторе точки.

Шрифты Tektur и Rubik используются из установленной обязательной системы `cyberpunk-red-core`; отдельные копии не включены. Значки — существующая библиотека Foundry Font Awesome. Остальные сведения об исходных компонентах: `THIRD_PARTY_NOTICES.md` и `docs/UPSTREAM.json`.
